# learnspanishwithdaniel.xyz

The website for **Español con Daniel**, Spanish lessons for Russian speakers.

- `index.html`: the landing page
- `placement-game/`: Palabra, a short arcade game that places a learner at their Spanish level

It's plain HTML with no build step, published with GitHub Pages from `main` to [learnspanishwithdaniel.xyz](https://learnspanishwithdaniel.xyz).

To preview locally, run `python3 -m http.server 8765` in this folder and open http://localhost:8765.
